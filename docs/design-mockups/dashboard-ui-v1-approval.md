# Dashboard UI v1 — tasdiq

2026-10-03 kuni foydalanuvchi `dashboard-ui-v1.png` maketini “Maqullayman” deb tasdiqladi.

Tasdiqlangan rasm: [Dashboard UI v1](dashboard-ui-v1.png).

Qamrov: desktop umumiy holat ekrani, to‘q ko‘k yon menyu, och fon, loyiha jadvali, AI signallari, faollik grafigi va bo‘limlar bloki. Rasmdagi shaxslar, raqamlar, sanalar va signallar namuna ma’lumotlaridir; ular ishlayotgan integratsiya yoki AI natijasi emas.

Frontend texnologiyasi va versiyalari hali tanlanmagan. Mobil ko‘rinish va boshqa sahifalarning batafsil dizayni ushbu tasdiqqa kirmaydi. Mahsulot AI lokal ishlashi talabi saqlanadi.

## Keyingi kichik tasklar

1. UI-01: frontend texnologiyasi va lokal ishga tushirish usulini asoslash, loyiha qarorini tasdiqlatish.
2. UI-02: tasdiqlangan ranglar, tipografiya, yon menyu va dashboard joylashuvini yaratish.
3. UI-03: dashboardni aniq belgilangan demo ma’lumotlar bilan ishlatish; mavjud bo‘lmagan API/inference natijalarini haqiqiy deb ko‘rsatmaslik.
4. UI-04: mavjud ruxsatli API yo‘llarini ulash; yuklanish, bo‘sh natija va xato holatlarini tekshirish.
5. UI-05: lokal ishlayotgan ekran screenshotini maket bilan solishtirish, mustaqil UI/UX va kod reviewi.

Yangi ekranlar va material dizayn o‘zgarishlari alohida rasm tasdig‘i bilan bajariladi. Ushbu tasdiq commit, push yoki server deploy ruxsati emas.
